# Glyphes de la carte de Savora

Glyphes SDF (format protobuf de MapLibre, plages de 256 caractères) des libellés
de la carte du Carnet. Générés par `scripts/gen-map-glyphs.py` du dépôt Savora,
à partir des fichiers TTF publiés par Google Fonts.

| Pile | Police d'origine | Licence |
| --- | --- | --- |
| `Savora Serif Regular`, `Savora Serif Italic` | Playfair Display (The Playfair Display Project Authors) | SIL Open Font License 1.1 — `OFL-Playfair-Display.txt` |
| `Inter Regular`, `Inter Medium`, `Inter SemiBold` | Inter (The Inter Project Authors) | SIL Open Font License 1.1 — `OFL-Inter.txt` |

« Playfair Display » est un nom de police réservé par sa licence : la version
convertie porte donc un autre nom (`Savora Serif`). Ces fichiers sont distribués
sous la même licence OFL 1.1 que les polices d'origine.
